📐 Mathematical Foundations & Theoretical Compendium

Rigorous mathematical formulations, proofs, loss functions, calibration metrics, and statistical significance tests in AdTech Machine Learning.

THEORETICAL COMPENDIUM

1. Bernoulli Maximum Likelihood & Log-Loss (Binary Cross-Entropy)

Ad click events follow a conditional Bernoulli distribution $Y \mid \mathbf{X} \sim \text{Bernoulli}(p(\mathbf{x}))$, where $p(\mathbf{x}) = \mathbb{P}(Y=1 \mid \mathbf{X}=\mathbf{x})$. Given independent observed impressions $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$, the log-likelihood is:

$$\ell(\boldsymbol{\theta}) = \sum_{i=1}^N \left[ y_i \ln \hat{p}_i + (1 - y_i) \ln (1 - \hat{p}_i) \right]$$ $$\mathcal{L}_{\text{LogLoss}}(\boldsymbol{\theta}) = -\frac{1}{N} \ell(\boldsymbol{\theta}) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln \hat{p}_i + (1 - y_i) \ln (1 - \hat{p}_i) \right]$$

Normalized Cross-Entropy (Rigged / NE): To remove dataset background CTR dependency ($p_{\text{base}}$), Normalized Entropy measures how much information the model adds beyond the naive prior:

$$\text{NE} = \frac{\mathcal{L}_{\text{LogLoss}}(y, \hat{p})}{-\left[ p_{\text{base}} \ln p_{\text{base}} + (1 - p_{\text{base}}) \ln (1 - p_{\text{base}}) \right]}$$

2. Negative Downsampling Odds Inversion (He et al., 2014)

In massive CTR systems, positive ad clicks are sparse (~16.9%). Non-clicks are downsampled by keeping them with probability $w \in (0, 1]$, compressing dataset storage while preserving all positive signals. Let $p' = \mathbb{P}(y=1 \mid \mathbf{x}, \text{sampled})$. By Bayes' Theorem:

$$\text{Odds}' = \frac{p'}{1 - p'} = \frac{\mathbb{P}(y=1 \mid \mathbf{x})}{\mathbb{P}(y=0 \mid \mathbf{x}) \cdot w} = \frac{\text{Odds}}{w}$$ $$\ln(\text{Odds}') = \ln(\text{Odds}) - \ln(w)$$

Inverting for the true calibrated probability $p$ yields the exact closed-form re-calibration formula:

$$p = \frac{p'}{p' + \dfrac{1 - p'}{w}}$$

3. Brier Score Decomposition & Expected Calibration Error (ECE)

The total mean squared error of probabilistic predictions (Brier Score) algebraically decomposes into three distinct physical components:

$$\text{BS} = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{p}_i)^2 = \underbrace{\sum_{k=1}^K \frac{N_k}{N} (\bar{p}_k - \bar{o}_k)^2}_{\text{Reliability (Calibration Error)}} - \underbrace{\sum_{k=1}^K \frac{N_k}{N} (\bar{o}_k - p_{\text{base}})^2}_{\text{Resolution (Discrimination)}} + \underbrace{p_{\text{base}}(1 - p_{\text{base}})}_{\text{Uncertainty (Base Entropy)}}$$

Expected Calibration Error (ECE): Measures the weighted absolute discrepancy between prediction confidence and empirical accuracy across $M$ reliability bins:

$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|, \quad \text{MCE} = \max_{m \in \{1,\dots,M\}} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

4. Statistical Hypothesis Testing: McNemar's Test with Continuity Correction

To verify that model differences (e.g. XGBoost vs Logistic Baseline) are genuine rather than random sample variation, McNemar's test is conducted on paired binary classification outcomes:

$$\chi^2 = \frac{(|b - c| - 1)^2}{b + c}, \quad \text{where } \begin{cases} b = \text{Model A correct, Model B incorrect} \\ c = \text{Model A incorrect, Model B correct} \end{cases}$$ $$p\text{-value} = 1 - F_{\chi_1^2}(\chi^2) = \text{erfc}\left(\sqrt{\frac{\chi^2}{2}}\right)$$

When $p < 0.05$, the null hypothesis $H_0: \mathbb{P}(\text{Model A correct}) = \mathbb{P}(\text{Model B correct})$ is rejected at the 95% confidence level.
